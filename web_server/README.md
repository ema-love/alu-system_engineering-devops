# Web Server

This project is part of the **ALU System Engineering & DevOps** curriculum.

## Learning Objectives

At the end of this project, I am able to explain:

- What is a web server
- What is Nginx
- How to install and configure Nginx
- How to configure a custom 404 page
- How to configure HTTP redirection
- How to transfer files to a remote server using `scp`
- How DNS and domain names work
- How to automate server configuration using Bash scripts

## Project Structure

```
web_server/

```

## Files

| File | Description |
|------|-------------|
| `0-transfer_file` | Transfers a file to a remote server using `scp`. |
| `1-install_nginx_web_server` | Installs and configures Nginx to serve the required webpage. |
| `2-setup_a_domain_name` | Contains the configured domain name. |
| `3-redirection` | Configures a permanent (301) redirect for `/redirect_me`. |
| `4-not_found_page_404` | Configures a custom 404 error page. |
| `5-design_a_beautiful_404_page.html` | Creative custom 404 page design. |
